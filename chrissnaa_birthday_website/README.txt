CHRISSNAA'S 21ST BIRTHDAY WEBSITE

Files:
- index.html: the responsive birthday website
- assets/chrissnaa.jpg: the rotated portrait used on the page

How to open:
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge, Firefox, or your phone's browser.
3. Tap "Open your surprise" for confetti and the birthday message.
4. The website attempts to play the Happy Birthday melody automatically on page load. Important: mobile browsers may block audible autoplay until the visitor interacts with the page; a website cannot override that browser restriction.

How to publish it free:
- GitHub Pages: create a repository, upload index.html and the assets folder, then enable Pages in repository Settings.
- Netlify: drag the extracted folder into Netlify's manual deploy area.

The page uses Google Fonts when internet is available; it falls back to local system fonts if not.
